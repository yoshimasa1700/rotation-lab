# 初版の検証記録

実施日：2026-10-15。

## 自動検証

- `npm test`：22テスト成功。固定seedの200ケースを含む。
- `npm run build`：TypeScript型検査とViteビルド成功。
- 依存パッケージ：バージョン固定、インストール時の監査で既知の脆弱性0件。

## ブラウザ操作

Chromium系ブラウザで、デスクトップ1280px幅とモバイル390px幅を確認した。

| 操作 | 結果 |
| --- | --- |
| A：Z +90° | 点(1,0,0)→(0,1,0) |
| A：q ↔ −q | Quaternion符号が反転し、表示行列は一致 |
| A：yawスライダーで右矢印 | 35°→36°、数値入力も同期 |
| B：pitch 90°→同値姿勢 | (0,90,0)と(30,90,30)の表示行列が一致 |
| C：±179°、u=0.5 | 通常のEulerとSLERPの姿勢差180° |
| C：unwrap有効 | 同じ中点で姿勢差0° |
| C：複数軸例、再生・停止 | 操作可能、停止ボタンが表示され停止する |
| C：最後まで再生 | u=1で終了する |
| D：適用順序の交換 | (1,0,0)と(0,−1,0)の結果と行列が左右で入れ替わる |
| E：回転→移動 | p_A=(1,1,0) |
| E：移動→回転 | p_A=(0,2,0) |
| E：逆変換 | 元の点(1,0,0)と姿勢に戻る。表示基準変更の説明あり |
| 390px幅のC・E | 横方向のドキュメントはみ出しなし。Cは比較シーンを縦に配置 |
| エラーログ | 実行時エラーなし |

[画面画像](../public/overview.png)と[補間操作のGIF](../public/interpolation.gif)を保存した。GIFはuを0.1ずつ変えた実画面の連続キャプチャで、リアルタイム性能の測定ではない。

## 残る制約

すべてのブラウザや実機端末を網羅した検証ではない。Three.jsの配信チャンクは約567kB（gzip約140kB）で、Vite既定の500kB警告が出る。数学とUIは別チャンクに分離済み。性能の数値目標や学習効果は未測定。
