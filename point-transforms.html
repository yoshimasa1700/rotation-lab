00 / BEFORE CALCULATING

点は同じ。表す座標系が変わる。

このページの座標変換では、空間内の点を動かさず、同じ点を別の座標系で表します。座標軸を固定して点自体を回す「能動回転」とは、何を変えているかが異なります。同じ形の式でも、添字と座標系を先に確認します。

W / C
Wは世界座標系、Cはカメラ座標系。カメラの軸はxが右、yが下、zが前の右手系です。
pW / pC
同じ点の世界座標 / カメラ座標。すべて列ベクトルで扱い、(1, 0, 4)ᵀのようにも書きます。
RWC
Cで表したベクトルをWでの表現へ変える回転行列。
tWC
カメラ原点を世界座標で表した位置。点の座標と並進の単位はmです。

添字は「出力の座標系、入力の座標系」の順です。同次変換行列の表記では TWC = TW←C、つまり T_W_from_C を意味します。

pC =104
RWC =0−10100001
tWC =120

世界の軸方向はこの変換で定まります。世界のy軸が鉛直上向き、という追加の規約は置いていません。

01 / CAMERA → WORLD

向きをそろえて、原点の位置を足す。

pW = RWC pC + tWC

RWC pC は、カメラ原点から点へ向かうベクトルを、世界の軸で表したものです。その後にカメラ原点の世界座標 tWC を足すと、世界原点から見た点の位置になります。

① 回転行列を掛ける。各成分は「行と列」の内積です。

RWC pC =0·1 − 1·0 + 0·41·1 + 0·0 + 0·40·1 + 0·0 + 1·4= 014

② 原点の位置を足す。

pW =014+ 120= 134

点自体は同じ場所にあります。カメラ座標では (1, 0, 4)ᵀ、世界座標では (1, 3, 4)ᵀと表されています。

02 / WORLD → CAMERA

先に並進を引き、次に逆回転。

元の式から pC を取り出します。回転行列では、逆行列は転置 R⁻¹ = Rᵀ です。

pW − tWC = RWC pC
pC = RWCᵀ (pW − tWC)
= RWCᵀ pW − RWCᵀ tWC

pC = RCW pW + tCW という形で書くなら、次の2つをセットで求めます。

RCW = RWCᵀtCW = −RCW tWC

逆変換の並進は、符号を変えるだけではありません。tCW は「世界原点をカメラ座標で表した位置」です。tWC とは表現する座標系が違うため、逆回転も必要になります。

RCW =010−100001
tCW = −2−10= −210

まず RCW pW だけを計算します。第2成分は −1 × 1 + 0 × 3 + 0 × 4 = −1。回転前のy成分「3」をそのまま使わないようにします。

pC =3−14+ −210= 104

最初の点に戻りました。もう一つの確認方法は、先に pW − tWC = (0, 1, 4)ᵀ を計算してから逆回転することです。

03 / CAMERA → IMAGE

位置の比を、画像のピクセルへ。

レンズの歪みを無視したピンホールカメラを考えます。投影に使うのはカメラ座標 pC = (XC, YC, ZC)ᵀ です。世界座標の点は、まずカメラ座標へ変換します。

画像のuは右、vは下に増加します。焦点距離は fx = fy = 400、主点は (cx, cy) = (320, 240)。これらと画像座標の単位はピクセルです。

u = fx XCZC + cxv = fy YCZC + cy

ZC は光軸方向の深さです。カメラから点までのユークリッド距離 √(XC² + YC² + ZC²) とは異なります。ここではカメラ前方の ZC > 0 を扱います。ゼロなら式は未定義、負なら点はカメラの後ろです。

点 (1, 0, 4)ᵀ の投影：

u = 400 × 1/4 + 320 = 420v = 400 × 0/4 + 240 = 240

点を2倍した (2, 0, 8)ᵀ の投影：

u = 400 × 2/8 + 320 = 420v = 400 × 0/8 + 240 = 240

両方とも (u, v) = (420, 240)。画像上の位置は変わりません。1/4 = 2/8なので、カメラから同じ方向にある点は、深さが異なっても同じ位置に投影されます。

TRY / SAME RAY, SAME PIXEL

点を光線上で動かしてみる。

カメラの姿勢は固定し、点を pC = λ(1, 0, 4)ᵀ に変えます。λを変える操作では、空間内の点自体が移動します。

点の位置を変える
カメラ座標 pC / m
(1, 0, 4)
世界座標 pW / m
(1, 3, 4)
逆変換で戻した pC / m
(1, 0, 4)
画像座標 (u, v) / px
(420, 240)

画像座標だけで、奥行きは決まる？

この1枚の画像座標だけでは、一意に決まりません。カメラの内部パラメータが既知でも、分かるのは XC/ZC と YC/ZC という比です。正のλで点の全成分を同じ倍率にすると、比は変わりません。

u − cx = fx XCZC⇒ ZC = fx XCu − cx

この変形で深さを求められるのは、XCが別の情報から既知で、u ≠ cxのときです。画像座標だけではXCも未知なので、式を変形しても深さの情報は増えません。

04 / THREE PLACES I GOT STUCK

詰まったところを、次の確認に変える。

01

逆並進は、符号を変えるだけ？

逆変換の式 pC = RCWpW + tCW は正しい。求め直すべきなのは、その中身です。先に並進を引いて、次に逆回転と元の式からたどれば、tCW = −RWCᵀtWC と分かります。

02

戻した点が (1, 4, 4)ᵀになった。

第2成分を見直します。RCWpW の第2成分は、行と列の内積で −1 × 1 + 0 × 3 + 0 × 4 = −1。そこに並進の +1 を足すので0です。回転前のy成分を残して 3 + 1 としないよう、行ごとに計算します。

03

深さの式からfxが抜けた。

ZC = XC/(u − cx) ではなく、分子は fxXC です。(u − cx)ZC = fxXC を一度書くと、係数を落とさず変形できます。

05 / YOUR 45-MINUTE PRACTICE

式を隠して、もう一度説明する。

ここからは読者自身の自習用チェックリストです。紙とペンか短いコードを使い、同じ数値を計算してください。同じ疑問で3分止まったら記録して先へ進みます。

  1. 0〜5分
    座標系と値を書く。

    C → Wの矢印、列ベクトル、カメラの軸、単位を明記。pC、RWC、tWCを書き写します。

  2. 5〜15分
    世界座標へ変換する。

    回転と並進を別々に計算。「点が動いたのか、表し方が変わったのか」を説明します。

  3. 15〜25分
    逆変換で戻す。

    元の式を変形し、RCWとtCWを導きます。pCへ戻ることを確認し、並進の符号変更だけでは足りない理由を1文にします。

  4. 25〜37分
    2点を画像へ投影する。

    (1, 0, 4)ᵀと(2, 0, 8)ᵀを投影し、結果を比較。「画像座標だけで深さが決まるか」に理由を添えて答えます。

  5. 37〜45分
    2分で説明し、詰まりを残す。

    式を隠して「座標変換 → 逆変換 → 投影」を説明。詰まった箇所を最大3つ、次の形式で記録します。

  • どこで止まったか。
  • 何が分からなかったか。
  • 今はどう理解しているか。

3つ埋める必要はありません。数値が合うことに加え、どの座標系で表した量を、どの順番で計算したかを説明できれば、この練習の到達点です。
