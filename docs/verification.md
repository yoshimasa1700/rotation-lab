## ブラウザ操作

Chromium系ブラウザで、デスクトップ1280px幅とモバイル390px幅を確認した。

| 操作 | 結果 |
| --- | --- |
| A：Z +90° | 点(1,0,0)→(0,1,0) |
| A：q ↔ −q | Quaternion符号が反転し、表示行列は一致 |
| A：yawスライダーで右矢印 | 35°→36°、数値入力も同期 |
| B：pitch 90°→同値姿勢 | (0,90,0)と(30,90,30)の表示行列が一致 |
| C：±179°、u=0.5 | 通常のEulerとSLERPの姿勢差180° |
| C：unwrap有効 | 同じ中点で姿勢差0° |
| C：複数軸例、再生・停止 | 操作可能、停止ボタンが表示され停止する |
| C：最後まで再生 | u=1で終了する |
| D：適用順序の交換 | (1,0,0)と(0,−1,0)の結果と行列が左右で入れ替わる |
| E：回転→移動 | p_A=(1,1,0) |
| E：移動→回転 | p_A=(0,2,0) |
| E：逆変換 | 元の点(1,0,0)と姿勢に戻る。表示基準変更の説明あり |
| 390px幅のC・E | 横方向のドキュメントはみ出しなし。Cは比較シーンを縦に配置 |

## 操作性の改善（v1.0.1）

`e2e/interactions.spec.ts`に9つの実ブラウザテストを追加した。`npm run test:e2e`で本番ビルドを起動して実行する。GitHub Actionsも数学テストとブラウザテストの両方を通過しなければ公開しない。

- q↔−qの連続Enter操作と、補間例の切替後のフォーカス保持。
- `0.5`および`-0.5`を1文字ずつ入力し、スライダーと点座標が同期すること。
- 空欄の復元と、範囲外の値を確定したときの補正。
- モバイルの主操作領域が44px以上であること。
- 小さなドラッグ説明のコントラストが4.5:1以上であること。
- BとEの既知解、Cのunwrap・再生停止・終点。
- 全デモが320px幅でページを横にはみ出さず、実行時エラーなく切り替わること。

詳細な検出根拠と改善内容は[監査記録](audit-2026-10-15.md)を参照。
