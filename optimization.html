READING NOTE 01 / OPTIMIZATION

最適化でも、
回転を回転のまま。

なぜSO(3)・SE(3)が好まれるのか？

回転や位置姿勢を推定するときは、正しい幾何を保ちながら、必要な自由度だけを動かすと扱いやすくなります。そのための道具が、SO(3)・SE(3)上の状態と、Lie代数による局所更新です。

FIRST / 言葉の意味から

リー群とリー代数を、カメラで考える。

リー群は「変換そのもの」を集めたもの、リー代数は「変化の方向や大きさ」を計算するための空間と考えると入りやすくなります。

リー群：回す・動かす操作の集まり。

カメラを「90°回す」「回してから1m動かす」。こうした変換を続けて行うと、結果もひとつの変換にまとめられます。何もしない変換と、元に戻す逆変換もあり、順序を保てば計算の括り方を変えても結果は同じです。この性質を持つ集合を群といいます。操作の順序を交換できるとは限りません。

さらに、集合が滑らかな空間になっていて、合成と逆操作も滑らかならリー群です。変換の変化を微分で扱えます。回転の集合SO(3)と、回転＋平行移動の集合SE(3)は、その具体例です。

SO・SEの「Special」は、なぜ付く？

SOはSpecial Orthogonal、SEはSpecial Euclideanの略です。Orthogonal（直交）は長さや角度を保つ行列、Euclidean（ユークリッド）は通常の空間で距離を保つ変換を指します。(3)は空間が3次元という意味で、自由度の数ではありません。

直交行列の集合O(3)には、向きを保つ変換と、鏡に映すように向きを反転する変換が含まれます。行列式が＋1のものだけに限定した集合がSO(3)です。この条件を表す言葉が「Special」です。

O(3)に含まれる2種類の変換
変換 行列式 SO(3)
向きを保つ（回転） ＋1 含む
向きを反転する（鏡映など） −1 含まない

たとえばX座標だけを反転するM = diag(−1, 1, 1)は、点(x, y, z)を(−x, y, z)に写します。長さや角度は保ちますが、det M = −1で、右手の形を左手の形に変えてしまいます。右手をどれだけ回しても左手にはならないので、これは回転ではありません。

SE(3)のSpecialも、鏡映などの向きの反転を除く意味です。回転部分の行列式が＋1である、回転と平行移動の組を扱います。「特別に優れている」という意味ではなく、条件で対象を絞っているという意味です。

小文字のso(3)・se(3)は別の略語ではなく、SO(3)・SE(3)に対応するリー代数の記号です。

リー代数：ここから、どう変えるか。

「カメラをあと1°右へ向けたい」という修正量を、ベクトルのように計算する場所がリー代数です。回転に対応するso(3)は3成分、回転＋移動に対応するse(3)は6成分で表せます。大文字のSO・SEは変換の集合、小文字のso・seは対応するリー代数を指します。

最適化での使い方

修正量を計算する
↓ 指数写像で変換にする
↓ いまの姿勢に合成する

「いまの姿勢」と「そこからの修正量」を分けて扱います。具体的な更新式は、この先の節で見ていきます。

恒等姿勢とは「何も回転していない姿勢」。

物体のX・Y・Z軸が、それぞれ基準の軸と一致した状態です。Euler角なら(0°, 0°, 0°)、Quaternionなら(w, x, y, z) = (1, 0, 0, 0)、回転行列なら単位行列Iで表せます。

どの回転Rと合成してもRI = IR = R。掛け算の「1」に相当します。SE(3)の恒等変換では、回転に加えて平行移動もゼロです。

厳密には、リー代数は「何もしない変換」の位置での接空間に、変換の順序による違いを表す括弧積という演算を備えたものです。小さい変化だけに限定された空間ではありませんが、最適化では局所的な修正量を扱うために使います。

背景と定義：Solàほか、A micro Lie theoryのリー群・接空間・指数写像の説明。

01 / KEEP THE GEOMETRY

行列に足すだけでは、
長さまで変わってしまう。

回転行列Rは、RᵀR = Iかつdet R = 1を満たします。9個の数を自由に変えてよい行列ではありません。これらの条件を満たす3×3行列の集合がSO(3)です。

たとえば、恒等姿勢からZ軸に30°回す場合。θ = π/6 ≈ 0.5236として、微小回転の一次近似をそのまま新しい行列にする方法と、指数写像で回転を作る方法を比べます。

一次近似をそのまま使う

I + [δθ]×

⎡ 1.0000 −0.5236  0 ⎤
⎢ 0.5236  1.0000  0 ⎥
⎣ 0       0       1 ⎦

det ≈ 1.2742
単位Xベクトルの長さ ≈ 1.1288

回るだけでなく、XY平面内で伸びてしまう。

指数写像で回転を作る

exp([δθ]×)

⎡ 0.8660 −0.5000  0 ⎤
⎢ 0.5000  0.8660  0 ⎥
⎣ 0       0       1 ⎦

det = 1
単位Xベクトルの長さ = 1

長さを保って、ちょうど30°回る。

δθ = (0, 0, π/6)。数値は表示用に丸めています。一次近似の誤差を見やすくするため、ここでは30°を使っています。

一次近似は微分や線形化に役立ちます。ただし、加算だけで姿勢を更新し続けると回転の条件を外れます。指数写像による更新は、理論上その条件を保ちます。実装では浮動小数点誤差への配慮も必要です。

02 / SOLVE LOCALLY, COMPOSE GLOBALLY

状態を保ち、
「いまからの変化」だけを解く。

SO(3)・SE(3)は回転・剛体変換の集合（Lie群）。小文字のso(3)・se(3)は、恒等変換での接空間（Lie代数）です。基底を選ぶと、それぞれ3成分・6成分のベクトルで表せます。最適化ではこの局所的な増分を求め、現在の状態に合成します。

回転の更新 / 3成分

Rnew = R exp([δθ]×)

位置姿勢の更新 / 6成分

Tnew = T exp(δξ̂)

[δθ]×は、ベクトルとの外積を行列積として表す歪対称行列です。δξ = (δρ, δθ)と並べると、δξ̂は左上に[δθ]×、右上にδρ、最下行に0を持つ4×4行列になります。指数写像expが、その増分を有効な回転・剛体変換に変えます。

平行移動の3成分にも、規約がある。

δρは接空間での並進成分です。SE(3)の指数写像では回転と並進が結びつくため、一般にexp(δξ̂)の右上の並進ベクトルとδρは一致しません。

最小二乗法の、ひとつの反復。

推定姿勢Tでの予測と観測の差を、残差r(T)とします。Gauss–Newton法やLevenberg–Marquardt法では、次の手順を繰り返せます。

  1. 現在の姿勢の近くで線形化する

    r(T exp(δξ̂)) ≈ r(T) + Jδξ。Jは局所増分に対する残差のヤコビアンです。

  2. 6成分の修正量を求める

    線形化した残差を小さくするδξを求めます。LM法では減衰を加え、更新の大きさを調整します。

  3. 変換を合成し、そこで再び線形化する

    T ← T exp(δξ̂)。次の反復では、更新後のTを新しい基準にします。

回転だけなら未知の増分は3成分です。行列の9成分や同次行列の16成分を独立に最適化する場合に比べ、冗長な変数や回転条件の制約を避けられます。合成・逆変換・座標変換も同じ規約で記述できます。

Lie群・接空間・局所更新の背景：A micro Lie theory for state estimation in robotics（Solàほか）。

右から掛ける？ 左から掛ける？

このページではTが物体座標を世界座標へ写すとします。T exp(δξ̂)は物体側の座標で表した増分、exp(δξ̂) Tは世界側の座標で表した増分です。どちらも使えますが、残差・ヤコビアン・共分散の規約をそろえる必要があります。

また、回転はSO(3)上で更新し、位置は世界座標の3成分として加算するSO(3) × ℝ³の方法も有効です。SE(3)の指数写像だけが唯一の選択肢ではありません。

03 / REPRESENTATION ≠ UPDATE

Quaternionも、この方法と両立する。

「QuaternionかSO(3)か」という二者択一ではありません。単位QuaternionはSO(3)の要素を表す方法です。保存には4成分のQuaternion、最適化の更新には3成分の局所ベクトルを使えます。

保存する成分数と、局所更新の自由度
状態の保存方法 保存 局所更新
回転行列 9 3
単位Quaternion 4 3
同次変換行列 16 6
Quaternion＋位置 7 6

局所ベクトルから単位Quaternion δqを作り、qnew = q ⊗ δqと合成すれば、行列を保存せずに回転を更新できます。単位ノルムの維持やqと−qが同じ回転を表す点には、引き続き注意します。

実装例として、Ceres SolverのQuaternionManifoldも、保存空間4次元・接空間3次元を区別しています。増分のスケールや積の向きはライブラリの定義を確認してください。

Euler角では、なぜ難しくなる？

このサイトのZYX規約ではpitch = ±90°で、rollとyawの変化が独立でなくなります。異なるパラメータ方向が同じ姿勢変化を表すため、Euler角をそのまま最適化するヤコビアンが退化し、周辺でも数値的に扱いにくくなります。

現在の姿勢を基準とする3成分の局所更新なら、姿勢がEuler角のpitch = 90°に相当していても、この座標表現に由来する特異点を避けられます。ただし、観測そのものに情報がなければ、その不定性は残ります。

04 / KNOW THE LIMITS

幾何を整えても、解けない問題は残る。

局所更新は、最適化を組み立てやすくする道具です。目的関数が凸になることや、必ず正解へ収束することを保証しません。

  • 初期値と局所解。初期姿勢が遠い、対応点が間違っているなどの場合、別の解へ収束したり発散したりします。
  • 観測不足とゲージ自由度。たとえば点が一直線上なら、その直線まわりの回転を決められない場合があります。SLAMでは基準座標の固定なども必要です。
  • 回転と並進の尺度。ラジアンとメートルを単純に同列に扱うと重みが不適切になり得ます。残差の意味や観測の共分散に応じた設計が必要です。
  • 大域的な座標の限界。SO(3)全体を特異点なく一意な3成分で表すことはできません。主値の対数写像には回転角πで曖昧さがあり、小さな増分での更新と大きな姿勢差の扱いを区別します。

持ち帰る考え方

姿勢はSO(3)・SE(3)上に置く。
更新量は3・6成分で解く。
指数写像で変換にして、合成する。

保存形式と、最適化で動かす座標を分けて考えることが鍵です。
