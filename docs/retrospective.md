# 設計の振り返り

## 作ったもの

初版でA〜Eの5つのデモを実装した。明るい実験ノート風の画面で「操作 → 数値 → 理由 → コード」の導線を共通化し、各デモをURLの`#A`〜`#E`で直接開けるようにした。

## 防ぎたい誤解と実装判断

- **表現と群を混同する**：Euler角/QuaternionとSO(3)/SE(3)の役割を画面下部とREADMEで区別した。
- **成分数が自由度だと思う**：Quaternionのノルム、回転行列の行列式と制約を常時表示した。
- **Quaternionに変えれば特異なEuler入力も直ると思う**：Bでは同じ入力を使うことを明示し、物体の自由度との違いを説明した。
- **行列を左から順に適用する**：DとEで「Y → X」「回転 → 移動」を文章で併記した。
- **unwrapと3D補間を同一視する**：Cにunwrapと複数軸の2例を用意した。
- **移動量を単純に加算する**：Eで合成後の移動列を示し、R₁t₂+t₁に対応づけた。

## 検証の証拠

22の数値テストは未実装状態で失敗することを確認してから実装した。各軸の手計算可能な例と独立したThree.jsの実装を比較し、同じ関数を呼び直すだけの検証を避けた。固定seedの200ケースで群の不変条件を確認した。詳細は[検証ノート](math-notes.md)とGitHub Actionsのログを参照。

UIではプリセット、符号反転、同値姿勢、補間中点、unwrap、再生停止、変換順序、逆変換、キーボード操作と狭い画面を確認する。具体的な実施結果は[画面検証記録](verification.md)に残す。
